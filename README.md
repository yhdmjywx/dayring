# Dayring

Windows 上的日程小工具，把一天画成 24 小时圆环。每件事在一天的哪里、占了多久，都能直接看见。

## 能做什么

### 一圈就是一天

00:00 在正上方，时间顺时针走，转一圈回到午夜。色段的位置表示开始和结束，弧长表示占用的时间。红针指向现在，空白处是还没安排的时间。

启动后不选中任务，中心显示当前时段的安排，没有安排时留空。手动选中后显示该任务，编辑完成后回到当前进行的安排。

### 直接在圆环上安排

点击空白处新建，拖动色段换个时间，拖动两端白点调整长短。点击圆环中心的名称和时间直接编辑，选中后在圆环内侧的弧形控件中换色或删除。时间按 15 分钟对齐，每段最短 15 分钟。

### 跨过午夜，仍是一段

23:00–01:00 的安排顺着圆环经过午夜，连续显示为两小时的色段。

## 操作

| 操作 | 作用 |
| --- | --- |
| 点击圆环空白处 | 从该时间起新增一小时安排 |
| 点击色段或下方标签 | 选中安排 |
| 拖动色段 | 移动安排，时长不变 |
| 拖动两端白点 | 调整开始或结束时间 |
| 点击圆环中心的名称或时间 | 原位编辑任务属性 |
| 圆环内侧的弧形控件 | 选择五种颜色之一，或删除安排 |
| 时间旁的时钟 | 选择小时和分钟（00、15、30、45） |
| Enter / Esc | 提交 / 取消当前字段编辑 |
| Delete | 未编辑文字且未打开时间选择时，删除选中安排 |
| 撤销 / Ctrl + Z | 恢复最近删除的安排；编辑文字时不触发任务恢复 |
| Tab / Shift + Tab | 在名称、开始、结束之间切换 |

## 运行

需要 Windows 和 Rust 工具链。在项目目录运行：

```powershell
cargo run
```

第一次启动会带上五个示例安排，可以直接修改。改动自动保存，下次打开继续使用。

构建不带控制台窗口的版本：

```powershell
cargo build --release
```

生成的程序在 `target\release\dayring.exe`。

## 数据

日程只保存在本机，Dayring 不联网。默认文件：

```text
%APPDATA%\Dayring\schedule.json
```

换一个文件：

```powershell
cargo run -- --data D:\notes\today.json
```

日程文件无法解析时，会尝试将原文件备份为同目录下的 `.json.bak` 文件，再恢复示例安排。
